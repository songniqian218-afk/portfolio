【方法一：发整个文件夹（本地查看）】
把 portfolio_final 整个文件夹压缩发给对方
对方解压后，双击 portfolio_songniqian.html
用 Chrome 或 Edge 打开即可看到所有内容

注意：视频和PDF在本地需要用Chrome才能正常显示


【方法二：免费发布到网上（推荐！任何人可随时访问）】
使用 GitHub Pages，完全免费，生成一个网址

步骤：
1. 注册 GitHub 账号：https://github.com/signup

2. 新建仓库：
   - 点右上角 + → New repository
   - 名字填：portfolio（或任意英文名）
   - 选 Public（公开）
   - 点 Create repository

3. 上传文件：
   - 点 uploading an existing file
   - 把 portfolio_final 文件夹里所有文件拖进去
   - 点 Commit changes

4. 开启 Pages：
   - 进入仓库 → Settings → Pages
   - Source 选 Deploy from a branch
   - Branch 选 main，文件夹选 /root（或/docs）
   - 点 Save

5. 等待1-2分钟，会生成网址：
   https://你的用户名.github.io/portfolio/

把这个网址发给任何人，无需下载，直接在浏览器看！
